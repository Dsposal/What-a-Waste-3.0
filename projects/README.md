# Projects

This folder contains hackathon project submissions.

We recommend creating one folder per project:

/projects/project-name

Each project should include:

- A README.md describing the project
- Team members
- Data sources used
- Methodology
- Findings
- Links to any dashboards, notebooks or applications

## Example

/projects
└── waste-and-air-quality
    ├── README.md
    ├── analysis.ipynb
    └── outputs
